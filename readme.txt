**Welcome to Nerdy Logs!**
____________________________



This is my first ever big-ish project that I created for an exam. The inspiration came from the fact that I used to have a huge list of movies/series/anime that I wanted to watch with my husband, but then I lost that list. Now we keep guessing if the [insert media type here] we're looking at used to be in the list or not.



It does come in handy for me personally, as I can also use it for games. Where Steam does most of the job well, it doesn't factor in my ability to get distracted and forget what I was thinking of playing next.


All this being said, this is a very simple web app that creates a watch-/play-/readlist with all the different genres that I am personally interested in.

An admin can add more items to the app and a user can pick from those items or create new ones, which will not have a ready description or picture, but the user can choose to add custom ones.





Enjoy ~
